# CLIENT DEMO — UK HOME-VISIT PHYSIOTHERAPY WEBSITE

## ROLE

You are a senior frontend engineer + UI/UX designer + healthcare website designer.

Your task is to build a polished, production-quality FRONTEND DEMO for a UK-based home-visit physiotherapy service.

The primary goal is to deliver a convincing client-facing demo quickly.

DO NOT build a backend for this version.

DO NOT spend time implementing authentication, database integration, payment processing, CMS, real appointment scheduling, email delivery, or APIs.

Use realistic mock/static data and frontend-only interactions.
